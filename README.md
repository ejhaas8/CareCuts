# Care Cuts

Care Cuts is an independent Colorado volunteer program bringing free shaves, trims, styling, hygiene care, and take-home kits to people who cannot easily get to a barber chair.

## Website

The main site is in [artifacts/care-cuts](artifacts/care-cuts/).

## Run locally

Install dependencies with pnpm, then start the Care Cuts web artifact:

```bash
pnpm install
pnpm --filter @workspace/care-cuts run dev
```

The site uses a prefilled email draft for visit requests and volunteer interest submissions.
